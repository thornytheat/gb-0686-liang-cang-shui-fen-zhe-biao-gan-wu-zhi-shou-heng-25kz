# 粮仓水分折标与干物质守恒

使用者：粮库结算员。接收多车次化验与地磅文件，复核折标数量后向财务结算。

核心规则：保留干物质：标准重量=净重×(1-实测水分)/(1-标准水分)，杂质先扣，超限退收，舍入只在结算末端。

## 启动

```sh
docker compose up --build -d
docker compose exec -T app pytest -q
docker compose config --quiet
```

浏览器访问 http://localhost:18200 。首页已装载脏样例，可编辑CSV与参数后运行，也可上传文件。七个导航分别对应业务步骤。

## 模块

- M1 磅单接收：接收磅单并检查结构，入口 `/m/1`、`GET/POST /api/m1`。
- M2 水杂契约：校核水杂和单位，入口 `/m/2`、`GET/POST /api/m2`。
- M3 折标计算：扣杂后按干物质折标，入口 `/m/3`、`GET/POST /api/m3`。
- M4 车次归并：按版本裁决冲突磅单，入口 `/m/4`、`GET/POST /api/m4`。
- M5 仓批平衡：逐仓核对干物质平衡，入口 `/m/5`、`GET/POST /api/m5`。
- M6 结算复核：结算到分并保留尾差依据，入口 `/m/6`、`GET/POST /api/m6`。
- M7 批次追溯：检查行数平衡与证据摘要，入口 `/m/7`、`GET/POST /api/m7`。
- M8 分次提货：仓批按实扣干物质分次提货、即开即锁凭证，末次归零并与复核金额对账，入口 `/m/8`、`GET /api/m8`。

## 演示与复核

1. 运行默认样例，核查隔离原因与业务合计。
2. 修改CSV单元格或参数并重跑，保留行号与输入摘要。
3. 在最后一步复核，旧版本提交返回409。
4. 证据CSV包含采信行和隔离行，重跑相同内容复用批次。

## 分次提货与凭证（M8）

同一仓批分多次提货，首张凭证当天即可开出，不必等末次提完。

- `POST /api/m8/register` `{run_id}`：仅对**复核通过**的运行按仓批登记提货账户，目标金额取该仓批 M6 已复核金额之和。
- `POST /api/m8/take` `{run_id,bin,idempotency_key,taken_dry_kg}`：按本次实提干物质扣减余量并立即开凭证、金额锁定。
- `GET /api/m8/overview?run=`（或 `/api/m8`）：返回各仓批可提余量、凭证列表与对账结论，供 `/m/8` 页面展示。

规则：干物质是唯一守恒库存（整数微千克存储，避免字典序与浮点误差），`余量≥本次扣量` 在同一 `BEGIN IMMEDIATE` 事务内校验，超提返回 `409 OVER_DRAFT`；扣量与开单同事务，失败整体回滚。凭证金额用累计差额法到分，末次（余量归零）把累计钉到仓批复核金额，吸收全部分币尾差，因此提完时剩余量为 0 且凭证总额与仓批金额分文不差。`idempotency_key` 唯一，客户端用同一键重试只返回首张凭证、不重复开单、不重复扣量。

## 数据与目录

`app/modules/` 按业务切分；`sample_data/` 为UTF-8 BOM、GB18030及干净/脏样例；`tests/` 含规则与端到端测试。SQLite保存运行与复核，命名卷records保留重启后的记录。若需从头开始，可先停止服务并在确认不再需要记录后删除该项目records卷。

## 定义与边界

单一粮种，标准水分和单价由批次参数给出。不处理跨粮种价差、税费和在线地磅接入。4MB文件上限。

详细字段、计算定义与原因码见 `docs/DATA-DICTIONARY.md`，回归证据见 `docs/DEPTH.md`。
